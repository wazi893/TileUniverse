Features

Everything you need to run massively parallel simulations at scale.

⚡

GPU-Accelerated Execution

Depth-batched CUDA kernels with L2 cache-resident world layouts. Optimized for throughput, not latency.

🌐

Parallel Universes

Run 100+ independent worlds simultaneously. Each universe maintains isolated state while sharing GPU resources.

⏪

Reversible Physics

Full state history with O(1) temporal navigation. Rewind, fast-forward, or jump to any point in time.

🤖

RL Integration

Native Gymnasium and Stable Baselines 3 support. Train agents across parallel environments at GPU speed.

🧬

Multiple Rulesets

Game of Life, Rule 110, wire propagation, logic gates. Extensible architecture for custom rules.

🐍

Python-Native API

Clean, minimal API with NumPy integration. Zero-copy memory transfer where hardware supports it.

Quick Start

Get running in under a minute.

example.py 
import tileuniverse as tu

# Initialize 100 parallel universes
engine = tu.Engine(worlds=100, size=(256, 256), ruleset="gol")

# Randomize first world
engine.randomize(0, density=0.3)

# Evolve all worlds 1000 steps
engine.evolve(1000)

# Extract state as numpy array
world = engine.get_world(0)
print(f"Shape: {world.shape}")  # (256, 256)
pip install tileuniverse
