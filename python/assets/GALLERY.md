## Usage Guidelines

### README
```markdown
![TileUniverse Logo](assets/logo.svg)
![Hero Animation](assets/hero_animation.gif)
```

### Documentation
- Use `logo-dark.svg` on dark backgrounds
- Use architecture diagram for technical docs
- Reference whitepaper for detailed explanations

### Social Media
- Use `banner.png` for Twitter/GitHub headers
- Use `hero_animation.gif` for posts/demos
- Use throughput comparison for performance claims

### Presentations
- Start with logo + tagline slide
- Use architecture diagram for technical overview
- Use parallel worlds visualization for "wow factor"
- End with performance stats (40B evals/sec)
