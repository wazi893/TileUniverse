# TileUniverse Brand Guidelines

## Color Palette

| Name | Hex | Usage |
|------|-----|-------|
| **Midnight Black** | `#0d0f11` | Primary background |
| **Slate Gray** | `#1b1e22` | Secondary background, cards |
| **Soft White** | `#eaeaea` | Primary text |
| **Muted Gray** | `#666666` | Secondary text, captions |
| **Quantum Cyan** | `#00e4ff` | Accent, highlights, links |
| **Deep Cyan** | `#0099aa` | Gradient endpoint, hover states |

## Typography

**Primary Font:** Inter, SF Pro Display, system-ui, sans-serif

| Element | Weight | Size |
|---------|--------|------|
| H1 | 600 (SemiBold) | 36px |
| H2 | 600 (SemiBold) | 24px |
| Body | 400 (Regular) | 16px |
| Caption | 400 (Regular) | 11px |
| Code | Mono | 14px |

## Logo Usage

- **Minimum size:** 200px width
- **Clear space:** Maintain padding equal to the grid icon height
- **Dark backgrounds:** Use `logo-dark.svg`
- **Light backgrounds:** Use `logo.svg`

## Visual Language

### Grid Motif
The 4×4 grid represents parallel universes. Mix of filled (active) and outlined (potential) cells suggests dynamic simulation state.

### Gradient
Cyan gradient flows from bright `#00e4ff` to deep `#0099aa`, representing energy and depth.

### Tone
- Clinical, precise
- Confident but not arrogant
- Technical authority
- Research-grade polish

## Writing Style

**Do:**
- "TileUniverse achieves 40B evals/sec"
- "Simulation substrate for parallel discrete worlds"
- "GPU-accelerated execution"

**Don't:**
- "TileUniverse is super fast!"
- "Amazing parallel simulation tool"
- "The best GPU engine ever"
